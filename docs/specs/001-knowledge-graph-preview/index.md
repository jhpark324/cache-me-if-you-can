# 001 — 폐기한 그래프 디자인 시안

- 처리일: 2026-11-02
- 상태: 디자인 참고 기준에서 폐기, 활성 기능 명세에서 제외

사용자가 세부 디자인은 별도로 진행하고 그래프 라이브러리만 채택하기로 결정했다. 기존 색상·배치·노드 모양·화면 흐름·샘플 문구를 새 제품 디자인의 요구사항으로 사용하지 않는다.

- 현재 기술 결정: [ADR-004 — 3D 그래프 라이브러리 채택](../../decisions/ADR-004-graph-visualization-library.md)
- 과거 코드·검증 결과: [보관한 그래프 실험](../../research/archived-graph-preview/index.md)

이 경로는 이전 문서 참조를 위한 폐기 안내만 남긴다. 001 번호는 재사용하지 않으며 새 제품 화면은 별도 기능 명세로 작성한다.
