## 구현·검증 상태의 구분

T-001~006과 T-008~018은 구현과 기록된 검증 범위를 완료했다. 실제 로그인·모델 응답·출처 연결·강제 갱신, 실행 앱의 로그인 시도 취소, 실제 Codex 도구 왕복과 사람이 승인한 삭제를 확인했다. Codex 제품 폼 응답은 검증 클라이언트를 통해 전달했으며 네이티브 확인창의 시각 렌더링 검사는 별개다. 실계정 로그아웃 후 재로그인·네이티브 OS 관문은 T-007에 남긴다. 모델 토큰 수는 카탈로그에 정확한 토크나이저가 없어 보수 추정이며, 소규모 평가 한계는 [검증 기록](validation.md)을 따른다.
