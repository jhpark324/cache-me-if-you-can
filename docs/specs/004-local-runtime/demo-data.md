# 실제 저장소 체험용 테스트 데이터

- 상태: 추가·검색·웹 표시 확인 완료
- 기준: 2026-11-02 사용자 요청 “실제 테스트 데이터를 넣어줘”
- 대상: 현재 제품 서버 `http://127.0.0.1:8000/`
- 데이터: [합성 데이터 원본](artifacts/demo-data/dataset.json)

이 문서는 최초 12개를 추가한 당시의 유형·검증 기록이다. 현재 유형은 6개로 통합했으며 추가 40개와 새 MCP 검증은 [여섯 유형·대화 저장 시나리오](record-kinds-and-scenarios.md)에 기록한다. 아래 과거 원본과 결과는 당시 증거로 보존한다.

이번 요청은 앞선 읽기 전용 예시와 달리 실제 로컬 저장소에 기록을 추가하는 명시적 요청이다. 기존 기록을 수정하거나 삭제하지 않고 정상 웹 API로 추가한다. 제목에 `[테스트]`를 붙이고 본문에도 가상 내용임을 표시한다. 실제 사용자의 선호·감정·경험이나 확정된 서비스 명세로 간주하지 않는다.

## 구성

- 기록 12개, 기록 유형 9종
- 주제 5개: 데모 데이터, 학습과 기억, 프로젝트 설계, 일상과 회고, 아이디어와 실험
- 원문 구간에 연결된 Node 8개
- 명시적 기록 관계 12개와 기록·Node의 주제 연결
- 기본 공개 범위는 기존 정책인 `public`을 따른다. 외부 공유를 활성화하는 작업은 아니다.

제목·본문·유형·주제·관계 정의는 원본 JSON에서 확인한다. 반환된 ID와 작업 결과는 완료 후 함께 기록한다. 저장 후 상세 조회·출처·색인·검색·실제 홈 그래프를 확인한다. 삭제는 자동으로 수행하지 않으며 기존 사용자 재확인 규칙을 따른다.

## 저장 결과

- 실제 저장한 기록 12개 모두 색인 `ready`, 출처 상태 `valid`.
- 주제 5개·본문 Node 8개·명시적 관계 12개를 추가했다.
- 홈 그래프 25노드·63간선, 잘림 없음. 간선에는 기록/Node의 포함·주제 연결도 포함한다.
- 전체 기록 12개와 Node 구간 8개의 출처 조회가 원문과 일치했다.
- “질문 카드 복습”, “산책 감정”, “검색 출처 패널”은 각각 검색 결과를 반환했다. 이번 확인은 로컬 검색이며 새 AI 답변 생성 검증은 아니다.
- 실제 웹의 Canvas 표시와 연결 목록에서 출처 열기까지 확인했고 JavaScript 오류는 없었다.
- 기존 기록은 추가 전 0개였다. 로그인과 설정은 변경하지 않았다.
