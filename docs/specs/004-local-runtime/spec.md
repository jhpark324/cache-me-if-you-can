# 명세

기획과 디자인 시안을 실제 로컬 데이터로 동작하는 제품에 연결한다. 제품 이름은 **Cache Me If You Can**이다. 홈은 003의 그래프·검색·답변·출처 구성을 실제 데이터와 연결한다. 그래프는 상한이 있는 개요이며 무제한 전체 저장소를 한 번에 로드하거나 목데이터를 사용자 기록으로 넣지 않는다.

## 수용 기준

- AC-001: SQLite 기록 저장·정정·확인 후 소프트 삭제가 웹과 MCP에서 같은 도메인 서비스로 처리된다. 삭제 사용자 확인이 지원되지 않으면 실패한다.
- AC-002: 자체 ChatGPT OAuth PKCE 로그인은 state/nonce/서명/issuer/audience/계정 일치를 검사한다. 토큰은 브라우저·로그·백업에 노출하지 않는다. 모델은 계정 카탈로그에서 선택한다.
- AC-003: KURE-v2 CPU 청크 임베딩과 LanceDB 검색은 원본 전체를 보존하고 현재 revision/세대/삭제/출처 상태로 후보를 재검증한다. 준비 실패를 성공으로 표시하지 않는다.
- AC-004: LangGraph 위의 `create_agent` ReAct 에이전트는 단일 질문에서 읽기 도구를 자율적으로 선택한다. 요청당 도구 실행은 합계 최대 8회이며 한 응답의 병렬 호출도 각각 센다. 모델 호출·시간·입력 예산과 최종 근거 검증을 유지한다. 답변과 질문을 자동 영구 저장하지 않는다.
- AC-005: 제한된 지식 그래프와 검색이 첫 화면이고 최근 기록으로도 탐색할 수 있다. 답변은 검색 아래, 정확한 출처는 오른쪽 패널에 표시하며 그래프를 유지한다. 추가·편집·삭제 확인·유형/주제 필터와 선택 기록 1홉 그래프를 제공한다. 이전 요청이 새 결과를 덮지 않는다. 출처 재검토는 수정 본문·이유·직접 선택한 출처로 진행하고 기존 주제의 명시적 연결 정정도 제공한다.
- AC-006: 로컬 loopback 바인딩, Host/Origin 검사와 웹 세션/CSRF를 적용하고 MCP 토큰과 웹 확인을 구분한다.
- AC-007: 수동 백업은 일관된 SQLite snapshot과 manifest만 내보낸다. 로그인 토큰·모델·색인은 제외하며 내부 삭제 이력 포함 사실을 설명한다.
- AC-008: 재현 가능한 설치·실행 경로를 제공한다. 자동 검사와 실제 계정/Codex/각 OS 검증을 구분해 기록한다.
- AC-009: Codex용 기록 관리 스킬을 설치하고 MCP 연결을 재현 가능하게 등록한다. 설정에는 인증 비밀을 기록하지 않는다. 생성·정정 결과와 삭제 재확인/거부를 실제 클라이언트와 자동 계약 검사로 구분해 검증한다.
- AC-010: 자동 주제 연결은 긴 본문을 누락 없이 처리하고 실패 작업의 명시적 재시도를 웹과 MCP에서 제공한다. 갱신·로그아웃·취소 경합이 기존 인증/작업 상태를 되살리지 않는다.
- AC-011: 웹에서 대상과 내용을 검토한 명시적 병합, 근거·범위를 가진 관계 생성과 이유를 포함한 철회를 제공한다. 변경 결과를 확인할 수 있다.
- AC-012: 긴 질문의 처리 범위와 미처리 부분을 추적하고 선택 모델의 입력 예산을 검증한다. 한국어 학습·일상·메모의 검색/답변 평가를 재현 가능하게 남긴다.
- AC-013: [홈 그래프·브랜드 수용 기준](home-graph-refresh.md)의 빈 상태/실제 연결/화면 공존/이름/호환성/시각 검증을 충족한다.
- AC-014: [UI·UX 개선 기준](ui-ux-refinement.md)의 초안 보호·메뉴/상세 초점·조회 실패 복구·그래프 선택과 연결 탐색·반응형 조작·출처 저장일 표시를 충족한다.
- AC-015: [ReAct·개인정보 미들웨어 기준](react-agent.md)에 따라 도구 상한, 요청 간 격리, 필터·출처 재검증, `PIIMiddleware`의 모델 입력·출력 처리를 검증한다.
- AC-016: [통합 답변·작은 출처 표시](answer-reading.md)에 따라 웹 질문은 에이전트 답변만 요청하고, 하나의 자연스러운 글에 작은 출처 번호를 제공한다. 별도 관련 기록 목록을 로딩하지 않는다.
- AC-017: [검색 상단 배치·검색 근거 그래프](retrieval-graph.md)에 따라 중복 상단 도구를 제거하고, 질문에서 실제 읽은 근거 구간과 답변 인용 구간을 그래프에서 구분해 탐색한다.
- AC-018: [유형 단순화·Codex 저장 시나리오](record-kinds-and-scenarios.md)에 따라 6개 유형과 과거 값의 호환을 제공하고, 대화 후 명시적 저장을 가정한 합성 기록을 정상 MCP 경로로 추가·검증한다.

공유, 캘린더, 휴지통/복원, 자동 삭제, 다중 사용자, 검색 대화 이력은 제외한다.
