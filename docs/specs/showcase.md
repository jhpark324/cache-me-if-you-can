# 공개 프로젝트 소개

QR로 처음 방문한 사람은 별도 설치 없이 모바일에서 기록 저장, 출처 확인, 아티클 읽기를 이해하고, 관심이 생기면 GitHub README에서 설치 문서로 이동할 수 있다.

| 수용 기준 | 확인 방법 |
| --- | --- |
| 소개와 진입 | GitHub가 저장소 첫 화면에서 표시하는 README에 제품 화면, 실제 소개 사이트, 빠른 시작과 기술 문서를 연결한다. |
| 시연 | 합성 데이터를 넣은 실제 제품의 기능별 짧은 영상과 대표 화면을 제공한다. 대기 구간은 잘라 내고 화면에서 한 일과 결과를 함께 설명한다. 휴대폰에서 소리 없이 재생·정지·탐색할 수 있다. |
| 구조 | 두 Codex 스킬의 역할, 로컬 MCP와 웹의 진입 경로, 기록·검색 색인·아티클의 관계를 도식으로 보여 준다. |
| 관람객 질문 | 실제 사용 장면에서 생기는 궁금증을 골라 일상적인 표현으로 답한다. 예를 들어 기록의 주제 연결, 수정 후 과거 인용, 검색·답변 또는 외부 전송 범위가 어떻게 달라지는지 구체적 사례·전후 비교·짧은 경로 도식으로 보여 준다. |
| 읽기 흐름 | 소개 사이트에서 GitHub 저장소 링크는 상단의 독립된 탐색 요소로 제공한다. 설명·도식·시연 본문은 페이지 안에서 완결하며 GitHub 이동을 유도하지 않는다. |
| 디자인 | 제품과 같은 버전의 Astryx 구성요소와 테마를 사용한다. 제목·버튼·정보의 계층을 작은 화면에서도 알아볼 수 있게 하고 시연 선택과 출처 예시는 키보드로도 사용할 수 있다. |
| 모바일 | 320px 너비부터 본문·도식·영상 조작을 가로 스크롤 없이 사용할 수 있다. QR은 배포된 HTTPS 소개 주소로 연결한다. |
| 배포 | GitHub Actions가 소개용 정적 파일만 GitHub Pages에 배포한다. 로그인 없이 사이트와 영상, QR을 요청할 수 있고 방문자의 기기에서 개인 서재 서버 연결이 필요하지 않다. |
