# 공개 프로젝트 소개

QR로 처음 방문한 사람은 별도 설치 없이 모바일에서 기록 저장, 출처 확인, 아티클 읽기를 이해하고, 관심이 생기면 GitHub README에서 설치 문서로 이동할 수 있다.

| 수용 기준 | 확인 방법 |
| --- | --- |
| 소개와 진입 | GitHub가 저장소 첫 화면에서 표시하는 README에 제품 화면, 실제 소개 사이트, 빠른 시작과 기술 문서를 연결한다. |
| 하나의 학습 흐름 | TCP의 순서·재전송과 UDP의 독립적인 데이터그램을 공부한 같은 사람의 예시 대화를 사용한다. "캐시미 해줘"라는 요청, 둘로 나뉜 기록, 공통 주제로 연결된 그래프, 두 기록을 인용한 비교 아티클이 화면을 옆으로 넘길 때마다 이어진다. |
| 대화와 발견 | 첫 장은 TCP 질문, AI의 대답, UDP와의 비교, 사용자의 명시적 저장 요청 순서로 읽힌다. 같은 기록을 지식 공간에서 열거나 검색으로 다시 찾는 두 경로를 실제 제품 화면으로 보여 준다. 기본 그래프에서 세부 항목 노드를 선택해 본문 구간을 연다. 지식 공간에서 질문한 뒤에는 검색한 조각(청크)과 답변에 인용한 조각을 구분하고 원문을 확인한다. |
| 스킬과 MCP | 관람객은 기록하기와 아티클 쓰기 각각에서 자신이 할 말, Codex가 참고하는 스킬, MCP로 호출하는 도구와 결과가 보이는 화면을 연결할 수 있다. 저장과 발행을 구분하는 시각 자료를 첫 동선에서 발견하고, 시스템 구조와 세부 도구를 별도로 더 살펴볼 수 있다. |
| 진행과 움직임 | 첫 화면에서 바로 이야기를 시작하고 이전·다음 버튼과 현재 위치를 제공한다. 다음 장면은 사용자가 선택하며, 짧은 반복 애니메이션에는 정지 또는 정적 화면과 모션 감소 옵션을 제공한다. 자세한 실제 시연·작동 원리는 별도 상단 탐색에서 선택해 본다. |
| 발표 자료 | 소개 홈의 ‘발표 자료’에서 면접 전날 TCP·UDP 학습 기록을 다시 찾는 발표 슬라이드를 설치 없이 한 장씩 읽는다. HTML 뷰어에서 마우스·터치·키보드로 이동한다. JavaScript를 끈 경우 같은 슬라이드를 스크롤로 읽을 수 있다. 발표 탭은 열람만 제공한다. 소개 홈과 발표 자료 주소로 직접 진입할 수 있으며, 다른 섹션을 보는 동안에는 슬라이드를 미리 내려받지 않는다. |
| 시연 | 합성 데이터를 넣은 실제 제품을 발표용 노트북과 같은 가로 데스크톱 레이아웃에서 촬영한다. 휴대폰에서도 같은 전체 화면 사진·포스터·영상을 보여 주며 패널이나 가장자리를 잘라내지 않는다. 대기 구간을 편집하고 화면에서 한 일과 결과를 설명한다. 휴대폰에서 소리 없이 재생·정지·탐색하고 큰 화면으로 볼 수 있다. |
| 구조 | QR 기본 화면과 별도인 기술 가이드에서 기능, 시스템, 검색·데이터를 나누고 전체 지도에서 세부 계약까지 이동한다. 웹·MCP·스킬·서비스·저장소·운영 경계를 도식과 실제 도구 목록으로 설명한다. 기능 명세·기술 결정도 사이트 안에서 펼쳐 읽을 수 있어야 한다. |
| 설계 문서 탐색 | 소개 홈에서 ‘설계 문서’로 이동하면 첫 화면에서 이름과 역할이 표시된 Excalidraw 시스템 도식과 설명을 볼 수 있다. 문서 목차·장·절은 설명 주제명으로 표시하고, 기능 사용 예시는 관련 절 안에서 읽는다. 모바일에서도 분야와 현재 위치를 파악하고 다른 문서로 이동한다. |
| 동작 명세 | 스킬은 호출 조건·입력·작업 절차·저장 여부·결과로, MCP는 전송 경로·도구·필수/선택 입력·반환·오류로 정의한다. 기록 저장, 원문 조회, 아티클 발행의 호출 예시는 서버 스키마와 일치해야 하고 전체 도구의 실제 계약을 조회할 수 있어야 한다. |
| 저장 알고리즘 | 스킬이 보낸 주제 힌트, 서버가 기존 이름·별칭을 찾는 규칙, 새 주제와 기록의 연결, 힌트가 없거나 후속 처리가 실패한 경우를 실제 구현에 맞춰 설명한다. 같은 TCP·UDP 예시에서 입력을 바꾸면 어떤 주제와 기록이 남는지 도식과 사례로 확인할 수 있다. |
| 처리 경계와 예외 | 저장·검색·출처에 대한 심화 설명은 실행 주체, 처리 순서, 정상·예외 결과를 구별한다. 원문 보존과 파생 결과의 유효성을 구현·테스트와 대조하고, 관련 절을 스킬이나 시스템 문서에서도 찾아갈 수 있다. |
| 검색 심화 | 본문의 키워드·벡터 후보 결합과 주제 후보를 포함하는 기록 단위 결합을 구별한다. 구현과 같은 상수·순위 시작점을 쓰는 RRF 예제에서 입력 순위를 바꾸면 기여도와 결과 순서가 함께 바뀐다. |
| 관람객 질문 | 사용 시연과 기능 예시에서 생기는 궁금증은 관련 주제 절 안에서 답한다. 예를 들어 기록의 주제 연결, 수정 후 과거 인용, 검색·답변 또는 외부 전송 범위가 어떻게 달라지는지 구체적 사례·전후 비교·짧은 경로 도식으로 보여 준다. |
| 읽기 흐름 | 소개 사이트에서 GitHub 저장소 링크는 상단의 독립된 탐색 요소로 제공한다. 설명·도식·시연 본문은 페이지 안에서 완결하며 GitHub 이동을 유도하지 않는다. |
| 디자인 | 제품과 같은 버전의 Astryx 구성요소와 캐시미 다크 테마를 사용한다. 검정·차콜 바탕, 밝은 본문, 살구색 강조로 실제 제품과 색을 맞춘다. 제목·버튼·정보의 계층을 작은 화면에서도 알아볼 수 있게 하고 시연 선택과 출처 예시는 키보드로도 사용할 수 있다. |
| 모바일 | 320px 너비부터 본문·도식·영상 조작을 가로 스크롤 없이 사용할 수 있다. QR은 배포된 HTTPS 소개 주소로 연결한다. |
| 시각 검토 | 모바일의 첫 화면과 실제 조작 흐름을 개편 전후로 검토한다. 짧은 문장, 읽을 수 있는 그림 라벨과 터치 영역을 함께 확인하고 전체 녹화 화면은 원본 비율을 유지한다. |
| 배포 | GitHub Actions가 소개용 정적 파일만 GitHub Pages에 배포한다. 로그인 없이 사이트와 영상, QR을 요청할 수 있고 방문자의 기기에서 개인 서재 서버 연결이 필요하지 않다. |
