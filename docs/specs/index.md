# 현재 기능 명세

현재 제품의 동작과 수용 기준을 정의한다. 기능을 변경할 때 해당 명세와 관련 코드·테스트를 함께 확인한다. 설계와 계약은 공개 문서에 유지하고, 개발 세션의 대화·개인 실행 이력은 누적하지 않는다.

| 명세 | 범위 |
| --- | --- |
| [기록 관리](records.md) | 저장·revision·정정·출처·주제·관계·삭제·충돌 |
| [로컬 런타임](runtime.md) | 웹/MCP·로그인·색인·검색·에이전트·백업 |
| [지식 공간과 탐색](workspace.md) | 검색·3D·목록·타임라인·작성·출처·접근성 |
| [cache-me 스킬](cache-me.md) | 호출·저장·조회·정정·설치·검증 경계 |
| [학습 아티클과 개인 서재](articles.md) | 아티클 작성·등록, 시각화와 본문 내 출처 열람 |

수용 기준은 유지해야 하는 계약이며 모든 운영체제·모델·클라이언트의 검증 완료를 의미하지 않는다. 실제 지원 범위는 [플랫폼 문서](../architecture/platform-support.md), 검사 방법은 [테스트 가이드](../guides/testing.md)를 따른다.

작은 수정은 해당 명세를 갱신한다. 별도 제안이 필요한 변경은 의미 있는 영문 slug의 문서 또는 폴더로 작성하고 이 인덱스에 등록한다. 문제·범위·수용 기준·미정 사항을 먼저 정하고, 변경 규모에 맞게 설계와 재현 방법을 남긴다. [SDD 절차](../guides/sdd-workflow.md) · [템플릿](../templates/index.md)
