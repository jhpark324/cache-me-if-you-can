# 학습 아티클과 개인 서재

저장한 공부 기록을 다시 읽기 쉬운 한국어 아티클로 정리한다. Codex는 필요한 배경 설명과 예시를 보태고, 정확한 근거가 더 필요하면 공식 문서·논문 등 원문을 확인한다. 기본 독자는 나중에 주제를 다시 꺼내 볼 사용자다.

| 수용 기준 | 기대 동작 |
| --- | --- |
| AC-001 | 아티클 작성을 요청하면 스킬은 관련 지식을 찾아 원문을 읽고 완성한 글을 로컬 서재에 등록한 뒤 바로 여는 링크를 준다. 초안만 요청하면 대화에서 작성한다. |
| AC-002 | 제목·한 줄 요약·연결된 주제로 서재를 훑고, 상세에서 핵심 답과 사례·비교·흐름을 읽는다. 여러 절로 나뉜 긴 글은 목차로 이동할 수 있다. 내용에 맞게 Markdown 표, 단계 도식 또는 짧은 예시를 선택한다. 확인한 개인의 경험과 추가한 설명·가상 예시를 구별한다. |
| AC-003 | 본문의 번호를 선택하면 데스크톱은 옆 패널, 좁은 화면은 대화상자에 출처가 열린다. 주소·본문 스크롤을 유지하고, 패널을 닫으면 선택한 번호와 읽던 위치로 돌아간다. |
| AC-004 | 기록 출처는 인용한 버전·구간을 열고 변경·삭제 상태를 반영한다. 외부 출처는 읽은 원문의 제목·요지를 패널에 표시하고 사용자가 원문 열기를 선택하면 별도 탭에서 연다. |
| AC-005 | 등록된 글만 서재에 표시하고 고유 주소를 직접 열거나 새로고침할 수 있다. 일반 기록과 동일한 버전·삭제·재시도 규칙을 적용한다. 기존 자료 유형의 기록은 기존 상태를 유지한다. |

## 저장과 표시

기존 기록 생성 입력에 선택적인 `article`을 둔다. `summary`는 한 줄 요약이고 `citations`는 1부터 번호를 붙이는 순서 있는 목록이다. 기록 근거는 `{kind: "record", source: SourceRef}`, 외부 근거는 `{kind: "external", title, url, note}`로 표현한다. `note`는 원문에서 참고한 내용의 짧은 설명이다. 본문은 `[1](#cite-1)` 형태로 번호를 연결하고, 선형 흐름은 선택적으로 `article-flow` 코드 블록에 한 줄당 한 단계를 작성한다. 기록 근거를 기존 provenance에 포함하고 revision마다 본문과 해당 인용의 대응을 보존한다.

웹 메뉴와 목록 페이지의 이름은 ‘아티클’이다. 목록 경로는 `#articles`, 글 경로는 `#article/<기록 ID>`다. 웹은 `GET /api/v1/captures?articles_only=true`와 기존 상세 조회를 사용한다. 스킬 원본과 설치 진입점은 [스킬 인덱스](../skills/index.md)에서 관리한다. UI는 [Astryx 가이드](../guides/astryx.md)를 따른다.

출처가 바뀌면 본문에 해당 인용 번호와 상태를 표시한다. 기록 상세의 출처 재검토에서 교체할 번호와 새 버전·구간을 직접 고른다. 새 버전에는 선택한 근거를 반영하고, 나머지 번호와 외부 자료는 보존한다. MCP에서는 `capture_review_sources`의 `article`과 `replacement_sources`에 같은 대응을 제출한다.

같은 근거를 가리키는 번호가 여럿이어도 선택한 번호만 교체한다. 병합 화면에서 다른 아티클의 본문을 가져올 때는 가져온 번호를 원문 아티클의 출처로 표시한다. 대상 글에 이미 있는 같은 번호가 다른 자료를 잘못 가리키는 일을 막는다.
