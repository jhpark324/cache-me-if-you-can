# 검정 배경 지식 탐색 디자인 프리뷰

- 상태: `in-progress` — 흰색 글자·주황색 강조·더 어두운 무채색 유리로 팔레트 개정 중. 실제 제품 기능 구현과 구분한다.
- 작성일: 2026-11-02
- 기준: [MVP 기획](../../project/mvp-scope.md), 사용자가 제공한 검정 배경 그래프와 검색창 아래 응답·오른쪽 출처 패널 참고 이미지

## 목적과 범위

검정 배경에 지식 노드와 연결을 보여주는 화면을 목데이터로 구현하여 디자인을 검토한다. 얇은 연결선, 구체 노드, 읽을 수 있는 레이블, 왼쪽 탐색 영역과 검색 입력을 참고한다. 노드 강조 색상은 새로 구성한다. 이전에 폐기한 001 시안을 디자인 기준으로 되살리지 않는다.

프리뷰는 React JSX와 실제 Radix Themes·Lucide 컴포넌트를 사용하고 esbuild로 만든 정적 번들을 로컬에서 실행한다. 실제 제품의 TypeScript·Vite 통합, FastAPI·DB·임베딩·OAuth 구현이나 검색 품질 검증을 의미하지 않는다. 기존에 채택한 그래프 라이브러리 번들을 재사용할 수 있다.

## 화면과 동작

- 메인 배경은 검정 `#000000`이다. 사이드바와 읽기 패널은 검정 계열의 구분 가능한 표면으로 구성한다.
- 본문·탐색 글자는 흰색 계열로 표시하고 핵심 강조 문구와 인용 구간은 주황색으로 구분한다. 유리 표면과 반사광은 이전 v4보다 어두운 무채색 계열로 조정하되 오로라 테두리와 기존 모션은 유지한다.
- 검색·답변과 출처 패널은 유리 질감으로 다듬는다. 반투명한 어두운 표면, 배경 흐림, 은은한 밝은 테두리로 깊이를 표현하되 글자와 인용 구간을 선명하게 유지한다. 블러를 지원하지 않는 환경에는 불투명한 읽기 표면을 제공한다.
- 양옆 패널도 배경에서 떨어진 유리 표면으로 구성하고, 반사광·투명도·배경의 빛이 실제로 보이게 한다. 검색창 테두리에는 오로라 색이 흐르도록 하되 메인 캔버스의 검정색을 유지한다.
- 한국어 글꼴과 크기·굵기·명암을 재설계한다. 본문은 16px을 기준으로 하고, 제목·본문·보조 정보의 위계를 분명하게 구분한다. 의미가 반복되는 안내·프로필·워크스페이스 문구는 제거하되 필요한 버튼 이름과 목데이터 표시는 유지한다.
- 검색 응답의 펼침·접힘, 출처 패널의 열림·닫힘, 선택 상태에 연결된 모션을 제공한다. 읽는 본문을 계속 움직이지 않으며, 동작 줄이기 설정에서는 정적인 상태로 표시한다.
- 지식 그래프의 노드 선택과 탐색을 제공하며 유형 색상은 텍스트 범례와 함께 표시한다.
- 검색을 실행하면 검색창의 위치를 유지한 채 바로 아래에 현재 질문의 단일 목데이터 답변과 출처를 펼친다. 검색창과 응답을 하나의 연속된 패널로 구성하고 뒤의 지식 그래프는 유지한다. 별도 답변 페이지로 전환하거나 채팅 목록·후속 대화를 만들지 않는다.
- 답변 닫기는 응답 영역만 접고 입력한 질문은 유지한다. 다음 검색은 같은 영역의 답변을 교체한다.
- 출처를 선택하면 오른쪽 패널에서 해당 목데이터 저장본의 본문과 인용 구간을 보여준다. 다른 출처는 같은 패널에서 교체한다.
- 넓은 화면에서는 답변과 출처를 함께 읽을 수 있는 비모달 출처 패널을 제공한다. 좁은 화면에서는 출처를 전체 화면 모달 패널로 열고 닫으면 검색 결과로 돌아갈 수 있게 한다.
- 버튼·입력·선택 상태·도움말 등 공통 UI는 실제 UI 라이브러리 컴포넌트와 일관된 토큰을 사용한다. 라이브러리의 외형만 흉내 낸 구현을 라이브러리 적용으로 기록하지 않는다.
- 목데이터 프리뷰임을 화면에서 알린다. 실제 사용자 기록·모델 생성 결과처럼 표시하지 않는다.

## 수용 기준

| 기준 | 확인할 동작 |
| --- | --- |
| AC-001 | 검정 메인 배경과 지식 그래프·왼쪽 탐색·검색 입력이 첫 화면에 보인다. |
| AC-002 | 노드를 선택하거나 유형을 탐색하면 현재 선택·관련 내용이 화면에 반영된다. 색상 외에 이름·종류를 확인할 수 있다. |
| AC-003 | 검색 실행 후 검색창 바로 아래의 같은 패널에 질문 하나·답변 하나·출처가 표시되고 그래프 배경과 검색창 위치가 유지된다. 이전 대화 턴이 누적되지 않으며, 목데이터 범위를 벗어난 입력도 실제 검색인 것처럼 답하지 않는다. |
| AC-004 | 출처 선택으로 오른쪽 패널이 열리고 실제 목데이터 본문·인용 강조가 표시된다. 출처 교체·닫기가 작동한다. |
| AC-005 | 넓은 화면에서 답변과 패널이 겹쳐 읽기를 방해하지 않고, 모바일에서는 패널을 닫아 검색 결과로 돌아갈 수 있다. |
| AC-006 | 주요 버튼·입력은 키보드로 접근 가능하고 포커스를 표시한다. 출처 패널 닫기 후 적절한 위치로 포커스가 돌아간다. |
| AC-007 | 목데이터 표시, 검색 진행·빈 결과·오류 안내가 현재 상태와 일치하고 동작하지 않는 제어를 실제 기능처럼 노출하지 않는다. |
| AC-008 | 본문과 제어는 읽을 수 있는 대비를 유지하고 작은 화면에서 가로 넘침이 없으며 감소된 동작 설정을 존중한다. |
| AC-009 | 답변 닫기로 응답 영역만 접히고 검색 입력은 유지된다. 새 검색 결과는 같은 응답 영역을 교체한다. |
| AC-010 | React·Radix Themes·Lucide가 실제 설치·빌드되고 화면의 공통 UI에 사용된다. 검정 배경과 제품의 노드·출처 의미를 유지한다. |
| AC-011 | 검정 배경 위에 반투명 표면·배경 흐림·테두리의 유리 질감이 보이며, 답변·출처의 읽기와 조작을 방해하지 않는다. 배경 흐림을 지원하지 않아도 본문을 읽을 수 있다. |
| AC-012 | 왼쪽 탐색·오른쪽 출처가 이전 v4보다 어두운 무채색 유리 소재로 보이고 검색 테두리에는 오로라 강조가 유지된다. 본문·탐색 글자는 흰색 계열이며 본문은 16px, 핵심 강조와 인용은 주황색으로 읽을 수 있다. 반복 안내 문구 정리와 기존 모션을 유지한다. |
| AC-013 | 응답·출처의 열림과 닫힘에 연결된 모션이 작동하고 빠른 전환에서 오래된 콘텐츠가 복원되지 않는다. 동작 줄이기 설정에서는 반복 효과와 진입·퇴장 모션을 억제한다. |

## 경계

그래프 전경은 디자인 검토를 위한 프리뷰 구성이다. 제품의 기본 홈을 전체 지식망으로 바꾸거나 무제한 그래프를 제공하기로 확정하는 요구사항은 아니다. 채택할 디자인의 세부값은 프리뷰를 보고 조정한다. 실제 기록 저장·삭제·로그인·공유는 이번 시안의 범위가 아니다.
