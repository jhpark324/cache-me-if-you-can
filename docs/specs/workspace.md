# 지식 공간과 기록 탐색 명세

어두운 중성색 바탕과 따뜻한 포인트 색, Pretendard를 사용하는 로컬 지식 작업 공간이다. Astryx Neutral을 확장한 다크 테마와 공통 컴포넌트로 탐색·버튼·입력·대화상자의 일관성을 유지한다. 포인트 색은 주요 작업과 현재 선택에 집중한다. 홈의 검색·답변·실제 3D 그래프와 기록 목록·저장일 타임라인을 제공한다.

## 화면 동작

- 설정은 현재 ChatGPT 계정 하나와 연결·해제·교체 동작만 표시하며 이전 계정 목록을 노출하지 않는다. 답변 모델 선택은 로그인·목록 조회 상태에서도 찾을 수 있고, 선택한 모델이 지원하는 경우 추론 수준을 조정할 수 있다.
- 검색 설정은 기록을 검색할 수 있게 준비하는 과정임을 설명한다. 검색 모델 준비와 실패한 기록의 검색 준비 재시도를 구분하고, 재시도할 실패 기록이 없으면 재시도 동작을 표시하지 않는다. 준비 완료·대기·실패 건수를 사용자 용어로 표시한다.

- 사이드바에는 지식 공간·모든 기록·타임라인과 설정을 둔다. 기록의 작성·필터·탐색은 본문에서 수행한다.
- 화면의 도메인 명칭은 [도메인 용어](../project/domain-language.md)를 따른다. 본문의 `Node`는 상세·그래프·관계 선택에서 **세부 항목**으로 표시하고 기록 유형 **맥락**과 구분한다. 관계 선택값·표시 이름은 [기록 명세](records.md)의 공통 유형을 사용한다.
- 홈 상단 검색 아래에 하나의 답변과 작은 출처 번호를 표시한다. 그래프에서 검색 중 읽은 근거와 최종 인용 근거를 구분한다.
- 모든 기록은 유형·주제·정렬·페이지 탐색을 제공한다. 목록의 필터를 홈 그래프나 전체 질문에 숨겨 적용하지 않는다.
- 타임라인은 사건 발생 시점이 아닌 실제 `created_at` 저장일을 현지 날짜로 묶는다. 월 경계를 UTC로 변환해 서버 전체 기록에 적용한다. 유형·주제는 목록과 공유하고 월은 타임라인에만 적용한다.
- 목록의 제목순 정렬과 기간 필터는 현재 로딩된 일부 항목에만 적용하지 않는다. 로딩한 항목 수를 전체 기록 수로 표시하지 않는다.
- 상세 화면에서 편집·삭제 확인·관계·병합·출처 재검토·실패 재시도를 제공한다. 주제는 자동 연결 결과를 표시하고 수동 주제 정정 버튼·대화상자는 제공하지 않는다. 목록이나 타임라인으로 돌아가는 경로와 기록의 직접 링크를 유지한다.
- 출처는 인용 당시 revision과 구간을 보여주며 현재 기록과의 차이를 표시한다. 전체 본문을 열었으면 한 번만 표시하고, 일부 구간을 열었으면 ‘참조한 부분’으로 표시한 뒤 ‘기록 전체 보기’에서 같은 저장본의 전체 문맥을 펼친다. 넓은 화면에서는 오른쪽 패널, 좁은 화면에서는 초점을 관리하는 모달을 사용한다.
- 작성·편집은 Markdown 미리보기, 초안 보호, 중복 저장 차단과 버전 충돌 확인을 제공한다. 완료 상태·공개 범위는 명시적으로 변경한다.
- 설정에서 계정 연결·모델 선택·검색 모델 준비·백업을 제공한다. 로딩·실패·취소 상태를 성공으로 표시하지 않는다.
- 홈 그래프는 표시 중인 기록의 주제 연결 처리 중·대기·실패를 안내한다. 확정하지 못한 후보가 있어도 연결된 주제를 유지하며 정상 완료로 취급하고 검토 필요 안내나 사용자 확인 동작을 표시하지 않는다. 이전 응답에 `needs_review`가 있어도 같은 원칙을 적용한다. 주제 연결이 끝나거나 외부에서 기록이 바뀌면 보이는 홈 그래프를 갱신하되 숨겨진 화면에서는 반복 조회하지 않고 이전 요청의 응답으로 새 화면을 덮지 않는다.
- 주제 연결 실패는 사용 한도·로그인·권한·응답 형식에 맞는 복구 경로를 표시한다. 기록 간 의미 관계를 임의로 생성하지 않으며, 주제 연결·세부 항목 포함·명시적 관계를 간선으로 표시한다. 세부 항목의 주제 간선은 홈과 선택 기록의 주변 그래프에서 동일하게 보존한다.

## 수용 기준

| ID | 기준 |
| --- | --- |
| AC-001 | 핵심 메뉴·검색·3D·본문 탐색의 역할을 구분하고 실제 API의 결과를 표시한다. |
| AC-002 | 빈 상태·로딩·오류·더 보기·필터 초기화가 동작한다. 페이지 경계에서 중복을 만들지 않고 만료 커서는 처음부터 복구한다. |
| AC-003 | 저장일 그룹·월 필터·제목 정렬을 서버 전체 조건으로 적용한다. 현지 날짜와 UTC 월 경계를 검증한다. |
| AC-004 | 검색 취소·무효화와 request_id 검증으로 늦은 응답이 새 결과를 덮어쓰지 못하게 한다. |
| AC-005 | 초안·수정 충돌·삭제 재확인·정확한 출처·뒤로가기와 상세에서의 원래 보기 복귀를 보존한다. 출처가 전체 본문이면 중복 전체보기를 표시하지 않고, 일부 구간이면 ‘참조한 부분’과 같은 저장본의 전체보기를 제공한다. 과거 출처의 전체보기도 당시 본문을 유지한다. |
| AC-006 | 실제 3D와 검색 근거·주제 탐색을 제공하고 WebGL 대체 화면·접근성 목록·모션 제어를 유지한다. 숨긴 그래프의 반복 렌더링을 중단한다. |
| AC-007 | 데스크톱·태블릿·좁은 화면에서 탐색·읽기·작성을 할 수 있다. 그래프에서 연 긴 출처는 데스크톱 패널과 좁은 화면 모달에서 마지막 문단과 하단 동작까지 스크롤해 읽고 조작할 수 있다. 키보드 초점·모달 초점 복귀·가로 넘침과 빈 상태를 확인한다. |
| AC-008 | 주요 본문 대비 4.5:1, 의미 있는 제어·포커스 대비 3:1을 확인한다. 상태를 색만으로 구분하지 않고 OS의 축소 모션 설정을 존중한다. |
| AC-009 | 같은 도메인 대상을 상세·그래프·관계 선택에서 같은 이름으로 표시한다. 모든 지원 관계 유형을 선택·저장·표시할 수 있고 서버에서 거부하는 유형을 선택지에 넣지 않는다. |
| AC-010 | 설정에서 이전 계정 선택 없이 현재 연결을 관리한다. 낮은 데스크톱·좁은 화면에서도 설정 내용을 마우스·터치·키보드로 스크롤해 하단 백업 동작까지 접근할 수 있다. 모델 선택·지원되는 추론 수준·목록 재시도에 키보드로 접근할 수 있고, 설정을 다시 열거나 서버를 재시작해도 저장된 선택을 확인할 수 있다. |
| AC-011 | 검색 준비의 목적과 현재 상태를 설명하고 실패한 기록이 있을 때만 ‘검색 준비 다시 시도’를 제공한다. 재시도할 작업이 없는 결과를 재시도 성공으로 표시하지 않는다. |
| AC-012 | 주제 연결 처리 중·대기·실패를 홈에서 구분하고 실제 실패는 기록 상세에서 원인에 맞는 복구 방법과 재시도를 제공한다. 모호한 후보와 이전 `needs_review` 상태에 사용자 검토를 요구하지 않으며 수동 주제 정정 진입점과 대화상자를 표시하지 않는다. 비동기 연결 완료와 외부 변경이 보이는 홈 그래프에 반영되며 숨김·화면 전환·늦은 응답 경합을 처리한다. |
| AC-013 | 현재 세부 항목에만 주제가 연결된 기록도 주변 그래프에 해당 주제와 근거가 있는 간선을 포함한다. 노드·간선 상한, 현재 버전·삭제·출처 자격 검증을 유지하고 존재하지 않는 끝점의 간선을 반환하지 않는다. |
| AC-014 | 공통 UI는 같은 버전의 Astryx core·theme·CLI와 의미 토큰을 사용한다. 한국어 글꼴·다크 테마·절제된 따뜻한 포인트 색을 유지하고, 탐색·기록·편집·설정의 버튼과 대화상자가 같은 시각·키보드 규칙을 따른다. 외부 글꼴 요청 없이 동작한다. |
| AC-015 | 디자인 시스템 전환은 기록 API·삭제 확인·초안 보호·출처 버전·그래프 수명과 필터 범위를 바꾸지 않는다. 데스크톱과 좁은 화면에서 주요 작업, 모달 초점 복귀, Escape, 축소 모션, 가로 넘침을 다시 검증한다. |

자동 브라우저 검사는 [프런트엔드 테스트](../../frontend/tests)와 [검사 가이드](../guides/testing.md)를 따른다. 크기 에뮬레이션 결과를 실제 모바일 기기·모든 보조기기 지원으로 확대하지 않는다.
