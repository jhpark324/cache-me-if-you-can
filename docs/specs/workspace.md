# 지식 공간과 기록 탐색 명세

검정·회색·흰색과 Pretendard를 사용하는 로컬 지식 작업 공간이다. 홈의 검색·답변·실제 3D 그래프와 기록 목록·저장일 타임라인을 제공한다.

## 화면 동작

- 사이드바에는 지식 공간·모든 기록·타임라인과 설정을 둔다. 기록의 작성·필터·탐색은 본문에서 수행한다.
- 화면의 도메인 명칭은 [도메인 용어](../project/domain-language.md)를 따른다. 본문의 `Node`는 상세·그래프·관계 선택에서 **세부 항목**으로 표시하고 기록 유형 **맥락**과 구분한다. 관계 선택값·표시 이름은 [기록 명세](records.md)의 공통 유형을 사용한다.
- 홈 상단 검색 아래에 하나의 답변과 작은 출처 번호를 표시한다. 그래프에서 검색 중 읽은 근거와 최종 인용 근거를 구분한다.
- 모든 기록은 유형·주제·정렬·페이지 탐색을 제공한다. 목록의 필터를 홈 그래프나 전체 질문에 숨겨 적용하지 않는다.
- 타임라인은 사건 발생 시점이 아닌 실제 `created_at` 저장일을 현지 날짜로 묶는다. 월 경계를 UTC로 변환해 서버 전체 기록에 적용한다. 유형·주제는 목록과 공유하고 월은 타임라인에만 적용한다.
- 목록의 제목순 정렬과 기간 필터는 현재 로딩된 일부 항목에만 적용하지 않는다. 로딩한 항목 수를 전체 기록 수로 표시하지 않는다.
- 상세 화면에서 편집·삭제 확인·주제 정정·관계·병합·출처 재검토·실패 재시도를 제공한다. 목록이나 타임라인으로 돌아가는 경로와 기록의 직접 링크를 유지한다.
- 출처는 인용 당시 revision과 구간을 보여주며 현재 기록과의 차이를 표시한다. 넓은 화면에서는 오른쪽 패널, 좁은 화면에서는 초점을 관리하는 모달을 사용한다.
- 작성·편집은 Markdown 미리보기, 초안 보호, 중복 저장 차단과 버전 충돌 확인을 제공한다. 완료 상태·공개 범위는 명시적으로 변경한다.
- 설정에서 계정 연결·모델 선택·검색 모델 준비·백업을 제공한다. 로딩·실패·취소 상태를 성공으로 표시하지 않는다.

## 수용 기준

| ID | 기준 |
| --- | --- |
| AC-001 | 핵심 메뉴·검색·3D·본문 탐색의 역할을 구분하고 실제 API의 결과를 표시한다. |
| AC-002 | 빈 상태·로딩·오류·더 보기·필터 초기화가 동작한다. 페이지 경계에서 중복을 만들지 않고 만료 커서는 처음부터 복구한다. |
| AC-003 | 저장일 그룹·월 필터·제목 정렬을 서버 전체 조건으로 적용한다. 현지 날짜와 UTC 월 경계를 검증한다. |
| AC-004 | 검색 취소·무효화와 request_id 검증으로 늦은 응답이 새 결과를 덮어쓰지 못하게 한다. |
| AC-005 | 초안·수정 충돌·삭제 재확인·정확한 출처·뒤로가기와 상세에서의 원래 보기 복귀를 보존한다. |
| AC-006 | 실제 3D와 검색 근거·주제 탐색을 제공하고 WebGL 대체 화면·접근성 목록·모션 제어를 유지한다. 숨긴 그래프의 반복 렌더링을 중단한다. |
| AC-007 | 데스크톱·태블릿·좁은 화면에서 탐색·읽기·작성을 할 수 있다. 키보드 초점·모달 초점 복귀·가로 넘침과 빈 상태를 확인한다. |
| AC-008 | 주요 본문 대비 4.5:1, 의미 있는 제어·포커스 대비 3:1을 확인한다. 상태를 색만으로 구분하지 않고 OS의 축소 모션 설정을 존중한다. |
| AC-009 | 같은 도메인 대상을 상세·그래프·관계 선택에서 같은 이름으로 표시한다. 모든 지원 관계 유형을 선택·저장·표시할 수 있고 서버에서 거부하는 유형을 선택지에 넣지 않는다. |

자동 브라우저 검사는 [프런트엔드 테스트](../../frontend/tests)와 [검사 가이드](../guides/testing.md)를 따른다. 크기 에뮬레이션 결과를 실제 모바일 기기·모든 보조기기 지원으로 확대하지 않는다.
