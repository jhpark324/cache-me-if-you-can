MCP 도구 명세

Codex는 MCP를 통해 사용자의 로컬 서재를 읽고 씁니다. 도구마다 제출할 필드와 돌려받는 값이 정해져 있습니다.

전송과 인증호출 예시도구별 계약결과와 오류재시도와 삭제 확인

전송과 인증

  1. Codex 클라이언트설치한 cache_me 연결이 tools/list로 사용 가능한 도구를 확인합니다.
  2. 로컬 MCP 서버기본 주소 http://127.0.0.1:52761/mcp/에서 Streamable HTTP로 JSON-RPC 요청을 받습니다.
  3. 서재 서비스tools/call의 params.name과 params.arguments를 검사하고 기록·아티클·검색 서비스를 호출합니다.

설치기가 등록한 헤더 도우미가 로컬 앱의 Bearer 인증을 제공합니다. 서버가 포트를 다르게 사용하면 설치한 연결의 주소를 따릅니다. 서버는 로컬 Host와 요청에 포함된 Origin을 검사합니다. 웹 브라우저는 세션 쿠키와 변경 요청의 CSRF 토큰을 사용합니다. 외부 답변 모델 연결에는 별도의 ChatGPT OAuth 로그인이 쓰입니다.

기록 저장부터 인용 발행까지

아래 세 호출은 합성 UDP 자료와 빈 메모리 서재를 사용해 실제 등록 도구로 차례로 실행했습니다. 첫 호출이 돌려준 두 식별자가 다음 호출의 원문과 인용 대상을 결정합니다. 다른 서재에서 실행할 때는 그 서재가 반환한 식별자를 사용합니다.

첫 응답에서 주제 상태가 pending이면 본문 저장은 끝났고 분류 작업이 남았습니다. 서버가 힌트와 본문으로 주제를 고르는 과정은 주제 매칭과 등록에서 볼 수 있습니다.

도구별 입력과 반환

도구를 펼치면 등록된 입력의 필수 여부, 허용 타입, 기본값과 중첩 객체를 읽을 수 있습니다. 입력의 객체 이름은 arguments 아래의 실제 키입니다. 각 도구 끝에 SDK가 제공하는 전체 입력·출력 JSON Schema가 있습니다.

결과와 오류

성공하면 MCP 결과의 structuredContent에 schema_version: 1, ok: true, data가 들어갑니다. 서재 서비스가 요청을 거절하면 isError가 참이고 structuredContent는 ok: false와 error를 담습니다. 도구가 돌려주는 content의 텍스트는 같은 객체를 직렬화한 값입니다.

구분원인과 처리
UNAUTHORIZED로컬 MCP 인증이 없거나 올바르지 않으면 HTTP 401을 받습니다. 연결 설정과 헤더 도우미를 확인합니다.
MCP 입력 검사알 수 없는 도구, 누락된 필수 인자, 잘못된 UUID와 같은 입력은 SDK가 서비스 실행 전에 거절할 수 있습니다. 이때 클라이언트는 MCP 오류도 별도로 처리해야 합니다.
NOT_FOUND · INVALID_SOURCE_REF대상 기록이나 버전을 열 수 없거나 구간·세부 항목이 원문에 속하지 않습니다. 저장 결과의 정확한 참조를 확인합니다.
VERSION_CONFLICT · IDEMPOTENCY_CONFLICT기대 버전이 바뀌었거나 이미 사용한 요청 ID에 다른 내용을 보냈습니다. 현재본과 원래 요청을 대조합니다.
INDEX_NOT_READY · QUERY_TOO_LONG검색 색인을 준비하거나 모델의 질의 예산 안으로 입력을 나누어 다시 요청합니다.

도메인 오류에는 code, message, retryable이 있고 필요한 경우 details가 붙습니다. 위 표는 자주 만나는 오류를 정리했습니다.

재시도와 삭제 확인

  • 같은 쓰기 요청 재전송. request_id를 받는 쓰기 도구는 같은 호출자의 같은 요청을 다시 받으면 기존 처리 결과를 확인합니다. 연결이 끊겼다면 같은 ID와 같은 내용을 보냅니다. 정상 재처리 영수증에는 replayed: true가 표시됩니다.
  • 수정 충돌. 기록은 기대 기록 버전과 상태 버전, 아티클 개정은 기대 아티클 버전을 확인합니다. 충돌이 생기면 현재본을 다시 읽고 수정 내용을 결정합니다.
  • 삭제. capture_delete_prepare로 미리보기와 5분 동안 유효한 확인 토큰을 받습니다. capture_delete는 대상·버전·토큰을 검사하고, MCP 클라이언트가 사용자에게 확인 폼을 표시합니다. 승인된 삭제만 새로 커밋합니다. 거절·취소·확인 기능 미지원 시 기록은 보존됩니다. 모델 입력에는 사용자 승인 필드가 없습니다.
