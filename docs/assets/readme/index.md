# 제품 사용 예시 이미지

현재 웹 빌드와 백엔드를 별도 임시 저장소에서 실행해 촬영한 이미지다. 합성 기록 14개에 실제 검색 색인을 만들었으며, 검색 화면은 모델이 기록을 조회해 생성한 답변과 출처를 보여준다. API 응답이나 화면 내용을 촬영용으로 대체하지 않았다.

실제 사용자 기록과 계정 화면은 포함하지 않는다. 예시 데이터는 새 설치에 자동으로 생성되지 않으며, 한 질문의 답변을 일반적인 검색·모델 품질 평가로 해석하지 않는다.

화면을 갱신할 때는 사용 중인 저장소와 다른 임시 데이터 경로·포트를 사용한다. 저장일을 분산한 예제, 주제와 연결을 준비하고 검색 색인이 완료된 뒤 실제 화면에서 탐색한다. 촬영 후 임시 서버를 종료하고 예제 DB·색인·임시 인증 자료를 삭제한다.

데스크톱은 1440×960, 모바일은 390×844 viewport에서 촬영한다. 문서 설명과 화면이 일치하는지, 글자·메뉴가 잘리지 않는지 확인한다. 회차별 실행 로그·응답 시간·계정 상태는 공개 이미지 자산에 함께 저장하지 않는다.
