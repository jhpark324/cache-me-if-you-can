# Second Brain — 디자인 프리뷰의 제품 맥락

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

이 산출물은 React JSX·Radix Themes·Lucide를 esbuild로 묶는 디자인 검토용 로컬 정적 프리뷰다. [UI 라이브러리 선정](ui-library-selection.md)은 이번 개정의 구현 기준이며 제품 디자인의 최종 채택과 구분한다. 실제 제품의 React·TypeScript·Vite, FastAPI, SQLite·LanceDB 등 기술 기준은 [프로젝트 기획](../../project/index.md)을 따른다. 그래프는 이미 채택한 `3d-force-graph`·Three.js·`three-spritetext` 조합을 사용한다.

## Users

AI와의 대화에서 배운 지식, 경험, 감정, 아이디어와 선택의 이유를 정리하여 다시 찾고 활용하려는 개인 사용자다. 이번 시안은 한국어 목데이터로 검토한다.

## Product Purpose

정리된 기록을 쌓고 연결된 지식을 찾으며 답변의 근거를 확인한다. 원래 대화 세션 전체를 자동 보관하지 않는다. 저장 지식과 AI의 보충 설명을 구분한다.

## Operating Context

제품은 Windows·macOS·Linux에서 직접 실행하는 로컬 서버와 자체 웹, Codex MCP를 목표로 한다. 이번 프리뷰에는 실제 서버·모델·로그인 연결이 없고, 네이티브 배포 검증을 수행하지 않는다.

## Capabilities and Constraints

- 웹은 검색 요청마다 검색창 바로 아래의 같은 패널에 단일 답변을 보여준다. 그래프 배경과 검색 입력은 유지하고 답변만 닫을 수 있다. 이전 질문·답변을 다음 질문에 붙이는 채팅은 제공하지 않는다.
- 출처를 클릭하면 오른쪽 패널에서 실제 인용한 저장본과 구간을 읽는다.
- 사용자가 새로 제시한 검정 배경 그래프 이미지를 이번 디자인의 참고로 삼는다. 이전 폐기 시안은 디자인 기준이 아니다.
- 노드 선택·그래프 탐색·검색·출처 패널은 목데이터로 시연한다. 실제 지식 생성·영구 저장·삭제·공유는 이번 산출물의 범위가 아니다.
- 실제 제품의 삭제는 재확인 후 soft delete이며 휴지통·복원·자동 삭제 기능은 없다. 이 시안에서 해당 기능을 새로 도입하지 않는다.
- 메인 배경의 검정색은 사용자 지정이다. 노드별 강조색과 구체적인 화면 값은 시안에서 제안하고 조정할 수 있다.
- 본문·탐색 글자는 흰색 계열, 핵심 강조 문구와 인용 구간은 주황색으로 표시한다. 유리 표면과 반사광은 이전 v4보다 더 어두운 무채색 계열로 조정하며 검색 오로라와 기존 모션은 유지한다.
- 사용자는 UI UX Pro Max를 활용해 유리 질감이 분명히 드러나는 디자인을 요청했다. 양옆 패널을 배경에서 띄우고 반투명 검정 표면, 흐림, 반사광과 뒤쪽 빛을 함께 사용한다. 검색창에는 오로라 강조를 적용하되 메인 캔버스는 검정으로 유지한다.
- 한국어 글꼴·크기·굵기·명암을 다시 구성하고 본문은 16px을 기준으로 한다. 반복 안내·프로필·워크스페이스 문구를 줄이고 필요한 조작 이름과 목데이터 표시는 유지한다.
- 응답과 출처의 열림·닫힘, 선택 상태를 모션으로 연결한다. 본문을 계속 움직이지 않으며 동작 줄이기 설정에서는 반복 효과와 진입·퇴장 모션을 억제한다.

## Evidence on Hand

기존 [MVP 범위와 사용 흐름](../../project/mvp-scope.md), [003 명세](../../specs/003-knowledge-space-design/spec.md), 사용자가 제공한 그래프 스크린샷이 근거다. 화면의 기록·답변·개수는 예시 데이터이며 실제 사용자 활동이나 제품 성능의 증거가 아니다.

## Product Principles

1. 지식을 찾는 흐름과 근거를 확인하는 흐름을 이어 준다.
2. 기록의 발화자·적용 범위·당시 의미를 과장하지 않는다.
3. 목데이터 시연과 실제 제품 기능의 경계를 명확히 한다.
4. 디자인 프리뷰로 제품의 확정 범위를 조용히 확장하지 않는다.
