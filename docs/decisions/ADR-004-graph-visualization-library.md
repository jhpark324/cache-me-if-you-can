# ADR-004: 3D 지식 그래프 라이브러리 채택과 기존 디자인 시안 폐기

- 상태: `accepted`
- 작성일: 2026-11-02
- 관련 기능·설계: [기술 스택](../architecture/technology-stack.md), [지식 계층](../architecture/knowledge-layer.md), [기존 시안의 실험 이력](../research/archived-graph-preview/index.md)

## 배경

3D 지식 그래프 시안에서 라이브러리 조합과 기본 조작을 확인했다. 사용자는 해당 라이브러리를 채택하고, 기존 시안은 디자인 참고 자료로 폐기하며 세부 디자인은 별도로 진행하기로 결정했다.

이 결정은 그래프 시각화 기술의 채택이다. 기존 시안의 색상·타이포그래피·패널 배치·노드 모양·화면 구성·샘플 문구를 제품 디자인으로 승인한 것으로 해석하지 않는다.

## 검토한 대안

| 대안 | 판단 |
| --- | --- |
| `3d-force-graph` + Three.js + `three-spritetext` | 사용자가 채택했다. 시안의 3D 그래프·노드 선택·레이블 표시 조합을 검증한 근거를 이어간다. |
| Cytoscape.js | 기존 기술 스택의 2D 주변 그래프 추천안. 이번 선택으로 대체한다. |
| 시안의 디자인과 화면 코드까지 제품 기준으로 채택 | 사용자가 폐기했다. 세부 디자인과 제품 화면은 별도로 설계한다. |

## 결정

제품의 3D 지식 그래프 시각화에 아래 라이브러리를 채택한다.

| 라이브러리 | 역할 | 검증된 시작 버전 |
| --- | --- | --- |
| `3d-force-graph` | 3D 그래프 배치·노드와 연결선·상호작용 | 1.80.1 |
| `three` | WebGL 기반 3D 렌더링 | 0.180.0 |
| `three-spritetext` | 3D 공간의 텍스트 라벨 | 1.10.0 |

버전은 기존 실험에서 확인한 조합을 개발 시작점으로 기록한 것이다. 영구적으로 고정된 버전이나 모든 브라우저에서 지원이 완료된 조합을 뜻하지 않는다. 제품 의존성은 실제 프론트엔드 구현 시 lockfile에 고정하며, 업그레이드할 때 노드 선택·터치·카메라 조작·라벨을 다시 검증한다.

기존 시안은 활성 기능·디자인 참고 목록에서 제외한다. 코드·화면 캡처·목데이터·과거 명세는 [보관한 실험](../research/archived-graph-preview/index.md)에만 남긴다. 이 자료의 목적은 버전 호환성과 당시 검증 이력을 확인하는 것이며, 새 화면을 기존 시안에 맞추거나 UI 코드·스타일을 제품에 그대로 복사하는 기준으로 사용하지 않는다.

## 결과와 후속 조치

- 기술 스택의 Cytoscape.js 추천을 위 조합으로 교체한다. React·라우팅·상태 관리 등 나머지 추천안의 채택 여부는 별도다.
- 세부 디자인, 화면에서 그래프가 차지할 범위, 첫 공개 포함 범위, 노드 표시 상한, 레이아웃 정책과 API 연동은 후속 명세에서 정한다. 시안의 1/2단계 탐색·패널 구조 등을 자동으로 제품 요구사항으로 승계하지 않는다.
- 시안 검증은 WSL/Linux의 Chromium·SwiftShader 및 모바일 뷰포트/터치 에뮬레이션에서 수행했다. Windows/macOS 실제 브라우저, Safari/Firefox, 대규모 노드·한글 라벨 성능은 별도 검증한다.
- 기존 실험에서 Three.js 0.187.0 조합은 OrbitControls pointerup 오류가 있었고 0.180.0으로 고정한 뒤 재검증했다. 이 관찰을 라이브러리 전체의 일반적 결함으로 확대하지 않는다. [검증 기록](../research/archived-graph-preview/validation.md)
- 시각화 라이브러리는 SQLite의 기록·관계, LanceDB 검색, LangGraph의 답변 실행 역할을 변경하지 않는다.

## 대체 관계

- 대체하는 결정: 기술 스택 문서의 Cytoscape.js 추천 및 001 시안의 라이브러리 미확정 상태. 별도 기존 ADR은 없다.
- 이 결정을 대체한 기록: 없음.
