# ADR-004: 3D 지식 그래프 라이브러리 채택

- 상태: `accepted`
- 작성일: 2026-11-02
- 관련 설계: [웹 명세](../specs/workspace.md), [기술 스택](../architecture/technology-stack.md), [지식 계층](../architecture/knowledge-layer.md)

## 배경

기록·주제·명시적 관계를 제한된 3D 그래프로 탐색하고 노드 선택·카메라 이동·한글 라벨을 제공해야 한다. 렌더링의 책임은 저장·검색 도메인과 분리한다.

## 검토한 대안

| 대안 | 판단 |
| --- | --- |
| `3d-force-graph` + Three.js + `three-spritetext` | 3D 배치·상호작용·텍스트 라벨을 함께 구성할 수 있어 채택 |
| Cytoscape.js | 2D 연결 탐색의 대안. 현재 3D 표현 요구에는 채택하지 않음 |
| Three.js로 배치·선택·레이블을 직접 구현 | 제어 범위는 넓지만 그래프 상호작용과 수명 관리를 직접 유지해야 함 |

## 결정

`3d-force-graph`는 그래프 배치·노드·연결선·상호작용, Three.js는 WebGL 렌더링, `three-spritetext`는 3D 텍스트 라벨을 담당한다. 실제 버전은 [프런트 lockfile](../../frontend/package-lock.json)에 고정한다.

서버가 조회 상한과 현재 기록·관계 상태를 검사하고 프런트는 그 결과를 표현한다. 화면에서 합성한 검색 근거 그래프는 저장된 지식 그래프를 변경하지 않는다. 시각화 라이브러리가 기록의 의미나 관계의 사실성을 결정하지 않는다.

## 결과와 검증 기준

- 라이브러리 변경 시 노드 선택·터치·카메라 조작·한글 라벨·해제를 회귀 검증한다.
- 그래프의 노드·간선 상한과 잘림 표시를 유지하고 목록으로도 기록을 탐색할 수 있어야 한다.
- 키보드 탐색·감소된 움직임 설정·WebGL 실패 상태를 별도로 다룬다.
- 실제 Windows/macOS 브라우저, Safari/Firefox, 큰 그래프의 성능은 별도 검증이 필요하다. 에뮬레이션 결과를 해당 환경의 지원 완료로 표시하지 않는다.
- 재현 가능한 브라우저 확인 절차는 [검증 안내](../guides/testing.md)를 따른다.

## 대체 관계

- 대체하는 결정: 기술 스택의 Cytoscape.js 추천. 별도 기존 ADR은 없다.
- 이 결정을 대체한 기록: 없음.
