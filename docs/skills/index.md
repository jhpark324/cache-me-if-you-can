# 에이전트 스킬

| 스킬 | 사용 범위 |
| --- | --- |
| [cache-me](cache-me/SKILL.md) | `$cache-me` 또는 `cache-me, …`로 요청하는 기록 저장·조회·정정·완료·삭제 |
| [cache-me-article](cache-me-article/SKILL.md) | `$cache-me-article 하이브리드 검색을 아티클로 써줘`처럼 근거를 엮어 아티클 페이지에 글을 등록하거나 기존 글을 수정 |

원본은 이 폴더에서 관리한다. 설치·연결 명령은 [로컬 실행 가이드](../guides/local-development.md)를 따른다.
