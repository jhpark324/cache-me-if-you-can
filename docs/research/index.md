# 조사 자료 인덱스

제품 선택의 근거와 재현 가능한 실험을 관리한다. 조사 당시의 패키지·문서·환경과 현재 구현은 다를 수 있으므로 각 문서의 확인일과 제한을 함께 읽는다.

| 자료 | 읽는 조건 |
| --- | --- |
| [세컨브레인 비교와 차별화 검토](second-brain-comparison-2026-11.md) | 공식 자료 기반 제품 비교·태그 구조·차별화 근거와 한계를 확인할 때 |
| [KURE-v2 + LanceDB 적합성 검증](kure-v2-feasibility/index.md) | 고정 합성 자료·스크립트·측정 결과로 CPU 다중 벡터 검색 실험을 재현할 때 |

연구 결과만으로 실제 사용자 자료의 품질, 현재 앱의 성능, 모든 운영체제의 지원을 보장하지 않는다. 현재 제품 동작은 [기능 명세](../specs/index.md)와 [아키텍처](../architecture/index.md)를 따른다.
