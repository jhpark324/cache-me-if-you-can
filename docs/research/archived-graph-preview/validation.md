# 3D 지식 그래프 시안 검증

> 보관한 과거 실험 결과다. 2026-11-02 사용자가 기존 디자인 참고를 폐기하고 라이브러리만 [ADR-004](../../decisions/ADR-004-graph-visualization-library.md)로 채택했다. 이 문서의 UI 수용 기준·스크린샷은 현재 제품의 디자인 기준이나 구현 완료 증거가 아니다.

- 검증일: 2026-11-02
- 환경: 현재 WSL/Linux의 Playwright Chromium, SwiftShader 소프트웨어 WebGL. 브라우저 의존성은 작업용 임시 디렉터리에만 준비했다.
- 라이브러리: 3d-force-graph 1.80.1, Three.js 0.180.0, three-spritetext 1.10.0.
- 검증 대상: 독립 HTML 시안과 합성 데이터. 운영 서비스·실제 OAuth·임베딩·DB·운영체제별 배포 검증이 아니다.

## 검증 중 수정

- Three.js 0.187.0과 사용 라이브러리 조합에서 노드 선택 후 OrbitControls pointerup 오류가 발생했다. 0.180.0으로 고정한 뒤 다시 검증했다.
- 빠른 터치가 직전 호버 상태에 의존하지 않도록 pointerup 시 실제 3D 노드에 raycast한다. 이동량이 큰 드래그와 여러 손가락 동작은 선택에서 제외한다.
- 제목 스프라이트가 노드 선택을 가로채지 않도록 하고, 제목 크기를 화면 기준으로 조정했다. 겹치거나 화면 밖인 제목은 생략하고 호버·목록에서 전체 제목을 확인한다.
- 작게 표시되던 조작 문구와 낮은 대비를 조정했다.

## 한계

- 실제 Windows/macOS 브라우저와 Safari/Firefox는 미검증이다. 작은 화면 검증은 Chromium 뷰포트·터치 에뮬레이션이다.
- 한 번에 수천 개의 노드를 표시하는 성능은 측정하지 않았다. 현재 위치와 연결은 기획 검토용 예시이며 거리를 임베딩 유사도나 인과관계로 해석하면 안 된다.
- 공개 범위 필터는 시안의 표현 검토용이다. 서버 권한 검사나 실제 공유 기능을 구현하지 않았다.
- 화면 조작은 메모리에만 반영되고 새로고침하면 초기 목데이터로 돌아간다.
